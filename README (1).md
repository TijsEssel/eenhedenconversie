# Eenheden omzetten

Eenvoudige Streamlit-app die eenheden inleest uit `units.csv`.

## Lokaal starten

1. Installeer Python.
2. Open een terminal in deze map.
3. Voer uit: `python -m pip install -r requirements.txt`
4. Voer uit: `python -m streamlit run app.py`

## Bestanden

- `app.py`: de toepassing
- `units.csv`: de eenheden, dimensies en SI-factoren
- `requirements.txt`: Python-afhankelijkheden
